# 4fix · ช่างใกล้ฉัน 🔧

ไดเรกทอรีร้านซ่อมใกล้บ้าน — คอม/โน้ตบุ๊ก · ปริ้นเตอร์ · มือถือ · ทีวี · แอร์ · เครื่องใช้ไฟฟ้า · กล้อง · แบตเตอรี่
เริ่มจากนนทบุรีและพื้นที่ใกล้โรงเรียนชุมชนวัดบางโค แล้วขยายต่อ

**เว็บ:** https://notehoo.github.io/4fix/

## ใช้ทำอะไรได้
- เลือกหมวด ค้นหาชื่อร้าน/ซอย/หมู่บ้าน (เช่น "พระปิ่น 3")
- เรียงใกล้สุดก่อน นับจากโรงเรียน, ตำแหน่งปัจจุบัน (ปุ่ม 📍 ใกล้ฉัน) หรือจุดที่แตะบนแผนที่
- กดโทร / นำทาง / ดูรีวิวใน Google Maps ได้ทันที
- แผนที่จริง (OpenStreetMap) ใช้งานบนมือถือได้ รองรับโหมดมืด

## ข้อมูลมาจากไหน
- รวบรวมจากผลค้นหาสาธารณะของ Google Maps (หลายคำค้น × กริดพื้นที่) แล้วคัดแยกหมวด ตัดร้านซ้ำด้วย `place_id`
- ดาวรีวิวเป็นของ Google — **ใช้ประกอบการตัดสินใจเท่านั้น** ควรโทรสอบถามราคาและเวลาเปิดก่อนไปทุกครั้ง
- ระบบจัดอันดับความน่าเชื่อถือ (จำนวนรีวิว/กราฟดาว) อยู่ระหว่างทำ
- พบข้อมูลผิด/ร้านปิดแล้ว แจ้งเจ้าของโปรเจกต์ได้

## ความเป็นส่วนตัว (สถิติการใช้งาน)
เว็บเก็บสถิติแบบ **ไม่ระบุตัวตน** เพื่อปรับปรุงบริการ ส่งไปที่เซิร์ฟเวอร์ของโรงเรียน (`bangkho.ac.th/fixlog`):

| เก็บ | ไม่เก็บ |
|---|---|
| เปิดหน้า, อุปกรณ์/ขนาดจอ/ภาษา/เขตเวลา, เว็บที่ส่งมา | IP จริง (เก็บเฉพาะแฮชที่เปลี่ยนทุกวัน) |
| คำที่ค้นหา, หมวด/ระยะ/การเรียงที่เลือก, ค้นแล้วไม่เจอ | ชื่อ เบอร์โทร อีเมลของผู้ใช้ |
| ร้านที่กดโทร/นำทาง/ดูแผนที่ | ตำแหน่งแม่นยำ (ปัดเหลือ ~1 กม. และเฉพาะเมื่อกด "ใกล้ฉัน") |
| เวลาที่อยู่ในหน้า, เลื่อนลึกแค่ไหน, ข้อผิดพลาดของหน้าเว็บ | |

- เก็บ 180 วันแล้วลบอัตโนมัติ · ไฟล์ข้อมูลเข้าถึงจากภายนอกไม่ได้ · ดูสถิติได้เฉพาะผู้ดูแล
- เบราว์เซอร์ที่เปิด **Do Not Track** จะไม่ถูกบันทึกเลย

## โครงสร้างโปรเจกต์ (ต้นฉบับอยู่ในเครื่องเจ้าของ)
```
index.html   หน้าเว็บ (HTML+CSS+JS ไฟล์เดียว, Leaflet จาก CDN)
shops.json   ข้อมูลร้าน (id=place_id, name, cat, type, addr, phone, hours, rating, lat, lng)
hero.jpg · bg_*.jpg · mascot.jpg   ภาพประกอบ/พื้นหลัง สร้างด้วย Qwen-Image 2.0
```
ฝั่งเก็บข้อมูล (ไม่อยู่ใน repo นี้): `scrape.mjs` (Chrome headless + CDP ค้น Maps ตามกริด) → `merge.mjs` (จัดหมวด) → `enrich.mjs` (จำนวนรีวิว/รูป) และ `collect.php`/`stats.php` สำหรับสถิติ
